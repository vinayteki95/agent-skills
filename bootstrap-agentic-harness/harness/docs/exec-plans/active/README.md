# Active Exec Plans

Multi-step work currently in progress. One file per plan, named
`YYYY-MM-DD-short-name.md`, created from [`../_TEMPLATE.md`](../_TEMPLATE.md).

Each active plan must carry a **Progress log** with a dated entry per working
session (enforced by the `doc-freshness` sensor). Move a plan to
[`../completed/`](../completed/) and flip its status header when it's done.

See [`../../PLANS.md`](../../PLANS.md) for the workflow.
